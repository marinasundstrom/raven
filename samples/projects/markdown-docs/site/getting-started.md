# Getting started

[WidgetFactory](xref:T:Samples.Docs.WidgetFactory) creates a widget with a default
title. [Widget.GetTitle](xref:M:Samples.Docs.Widget.GetTitle) returns that title.

## Where to go next

Use the API reference menu to explore the public declarations, or return to the
[overview](index.md). This guide is authored as Markdown and published under a
custom URL without changing its source links.

## Highlighted Raven

```raven
let widget = WidgetFactory.CreateDefault()
let title = widget.GetTitle()
```

The same grammar and token colors are used on the Raven website and generated
API pages. Try the header's theme selector, then open
[Page controls](guides/page-controls.html) to see HTML content without an outline.
