# Raven libraries

Raven exposes runtime extensions, compile-time macros, and compiler APIs. Their
API references are generated by RavenDoc from the libraries and documentation
comments, and share this website’s navigation and search.

## Core extensions

`Raven.Core` provides the standard runtime vocabulary used by ordinary Raven
programs, including `Option`, `Result`, error helpers, parsing projections,
sequence extensions, unions, and JSON integration.

- [Learn how Raven.Core fits into the language](../compiler/raven-core-library.md)
- [Browse the Core extensions API reference](raven-core/)

## Macros

`Raven.Macros` provides the standard compile-time macros, including `quote!`,
`compile!`, `query!`, and the `Error` macros. Import `Raven.Macros.*` to bring
their short aliases into scope.

- [Learn how Raven.Macros is referenced and authored](../compiler/raven-macros-library.md)
- [Browse the Macros API reference](raven-macros/)

## Compiler APIs

`Raven.CodeAnalysis` provides syntax trees, compilations, semantic models,
symbols, diagnostics and workspace APIs for tools built around Raven.

- [Read the compiler documentation](../compiler/index.md)
- [Browse the Compiler APIs reference](raven-codeanalysis/)
